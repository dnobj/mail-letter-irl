MCP Setup for Letter IRL

Connect Claude Desktop or other MCP clients to send real letters

1 Get Your Personal Access Token

First, you'll need to generate a Personal Access Token (PAT) to authenticate your MCP client.

Go to Dashboard to Generate Token

Important: Your token will only be shown once when created. Make sure to copy and save it immediately!

2 Configure Claude Desktop

Add the following configuration to your Claude Desktop settings file:

Configuration file location:

  • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
  • Windows: %APPDATA%\Claude\claude_desktop_config.json
  • Linux: ~/.config/claude/claude_desktop_config.json
{
  "mcpServers": {
    "letter-irl": {
      "command": "npx",
      "args": [
        "mcp-remote",
        "https://letter-irl.up.railway.app/mcp",
        "--header",
        "Authorization: Bearer YOUR_TOKEN_HERE"
      ]
    }
  }
}

Replace YOUR_TOKEN_HERE with your actual Personal Access Token (starts with lirl_pat_).

3 Restart Claude Desktop

After saving the configuration file, restart Claude Desktop to load the new MCP server.

You should see "letter-irl" appear in the MCP servers list in Claude Desktop's settings.

4 Start Sending Letters!

Once connected, you can ask Claude to help you send letters. Try prompts like:

  • "Send a thank you letter to my friend John at 123 Main St, New York, NY 10001"
  • "Write and send a birthday card to my mom"
  • "Help me draft a formal letter and mail it"

Note: Each letter costs 2 credits. You can purchase credits from your dashboard.

Need Help?

If you encounter any issues:

  • Make sure your token is valid and hasn't been revoked
  • Check that the configuration file is valid JSON
  • Ensure Claude Desktop has been fully restarted
  • Verify you have credits available in your account
